## เงื่อนไขสำคัญ

- เครดิต $100 ใช้ได้ภายใน 12 เดือน ใช้กับ Azure Marketplace ไม่ได้
- ต่ออายุได้ทุกปีตราบที่ยังเป็นนักศึกษา
- 1 คนสมัครได้ 1 บัญชี
- ใช้เพื่อการเรียน การสอน และงานวิจัยที่ไม่ใช่เชิงพาณิชย์เท่านั้น
- เมื่อเครดิตหมด Azure จะถามว่าจะเปลี่ยนเป็นแบบจ่ายตามการใช้งานไหม ถ้าไม่เปลี่ยน บริการจะถูกปิด
- ได้ดาวน์โหลดเครื่องมืออย่าง Visual Studio และ SQL Server ฟรีผ่าน Azure Education Hub

## วิธีสมัคร

1. เปิดหน้าทางการ แล้วกด Start free
2. สมัครด้วยอีเมลมหาวิทยาลัย ไม่ต้องกรอกบัตรเครดิต
3. ดาวน์โหลดเครื่องมือฟรีได้ที่ Azure Education Hub
