## ได้อะไรบ้าง

- **GitHub Copilot** แบบ Copilot Student สำหรับนักเรียนที่ยืนยันตัวตนแล้ว
- โดเมน `.me` ฟรี 1 ปีจาก Namecheap
- สิทธิ์จากพาร์ทเนอร์อีกหลายสิบเจ้า เช่น JetBrains, Microsoft Azure, MongoDB, DataCamp, Frontend Masters

แต่ละสิทธิ์มีระยะเวลาไม่เท่ากัน ดูรายละเอียดของแต่ละตัวในหน้าทางการ

## วิธีสมัคร

1. มีบัญชี GitHub ส่วนตัว
2. ไปที่ Settings > Education benefits แล้วกด "Start an application"
3. แนบเอกสารยืนยันสถานะ เช่น รูปบัตรนักเรียน/นักศึกษาที่มีวันที่ ตารางเรียน หรือใบรับรองสถานภาพ
4. ถ้าระบบขออีเมลสถานศึกษา ต้องเพิ่มและยืนยันอีเมลนั้นใน GitHub ก่อน
